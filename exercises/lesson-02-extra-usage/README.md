# Статистика настоящего обращения

Это отдельный необязательный каркас после урока подключения модели.
Текущая функция: format_usage в model_stats.py. Запуск опыта: demo_usage.py.
Общие transport.py и configure_model.py совпадают с основным курсом.
Готовый usage_client.py использует их функции для получения исходного ответа сервиса.
Инструкция и подсказки находятся в TASK.md и дополнительном уроке.
