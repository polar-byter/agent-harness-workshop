# Подсказки к текущему заданию

Когда сервис возвращает ответ модели, программа получает не только фразу для пользователя. Вместе с ней приходят поля, описывающие состояние ответа и его части. Если просто напечатать весь результат, человек увидит служебную структуру; если брать первое попавшееся поле, можно пропустить нужный текст или принять незавершённый ответ за готовый.

Разберём это на подготовленном `data/response.json`. Мы заранее знаем, где в нём записан ответ о списках Python, поэтому сможем проследить, как функция `extract_answer` до него добирается. Она проверит завершение ответа, соберёт текстовые части и вернёт строку для показа пользователю.

Это часть подключения ИИ к приложению: результат внешнего сервиса нужно прочитать по его структуре и отделить содержимое от служебных сведений. После практики станет понятнее, почему "сервис что-то вернул" ещё не означает "программа получила готовый текст ответа".

Откройте `assistant.py` -> функция `extract_answer`.

Чтобы добраться до текста, сначала пройдём по элементам `output` и выберем сообщения, а затем просмотрим части их `content`. Здесь нужны два вложенных цикла: обращение только к первому элементу пропустило бы остальные части ответа.

Допишите уже начатую функцию по заготовке ниже, заполняя каждый `...` по подсказкам. Когда закончите, удалите строку `raise NotImplementedError(...)`; повторно добавлять заголовок `def` не нужно.

```python
def extract_answer(response: dict) -> str:
    if response.get('status') != 'completed':
        raise ValueError('Ответ модели не завершён')
    parts = []
    for item in response.get('output', []):
        if item.get('type') == 'message':
            for part in item.get('content', []):
                if part.get('type') == 'output_text':
                    parts.append(...)
    answer = '\n'.join(parts).strip()
    if not answer:
        raise ValueError('В ответе нет текста')
    return ...
```

Когда мы дошли до части с `type="output_text"`, из неё нужно взять `part["text"]`. Именно это значение добавьте в `parts`. В последнем пропуске верните `answer` - уже собранную строку.

Запись `response.get("output", [])` берёт поле `output`, а если его нет - возвращает пустой список. Аналогично работает `item.get("content", [])`. Метод `"\n".join(parts)` соединяет найденные тексты, ставя между ними перевод строки. Последующий `strip()` убирает пробелы по краям всего ответа. Если текста не оказалось, мы показываем ошибку вместо выдуманного ответа.

На данных файла `data/response.json` в `parts` окажется список `['Списки Python сохраняют порядок элементов.']`. После `join` и `strip` в `answer` будет одна строка с тем же текстом. В `demo.py` загруженный из файла словарь передаётся в `extract_answer`, а результат её вызова сохраняется в `result`. Именно строка после `return answer` попадает в эту переменную. Теперь демонстрация может напечатать ответ без служебных полей `status`, `output` и `type`. Мы не получили новый ответ от модели, а извлекли уже записанный текст из подготовленной структуры.
