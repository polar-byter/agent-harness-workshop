# Урок 1. Ограничиваем рабочую папку

[Открыть исходники этого урока](../../exercises/lesson-05-01-paths/README.md) / [Подсказки рядом с кодом](../../exercises/lesson-05-01-paths/TASK.md)

> **Где мы.** Помощник умеет искать по регламенту, отвечать и работать в ограниченном цикле. В последнем разделе он начнёт менять код - так работают Claude Code, Cursor и другие кодирующие агенты. Первым делом ограничим, какие файлы ему вообще можно трогать.
> `предложение модели -> [проверка пути] -> чтение -> правка -> проверка`

В интернет-магазине из нашего примера есть небольшой модуль расчёта стоимости заказа, `prices.py`, и в нём ошибка. Попросим модель предложить исправление. Но прежде чем программа прочитает или изменит файл по просьбе модели, нужно решить, с какими файлами работать разрешено. Модель может назвать `prices.py`, а может - `../outside.py`, то есть файл за пределами рабочей папки, или системный файл на диске.

Это тот же вопрос, что администратор задаёт перед тем, как пустить агента к серверу: что именно ему доступно. Ответ на него должен быть записан в коде. Функция `workspace_path` получит имя файла, вычислит полный путь и проверит, что он лежит внутри учебной папки `workspace` и оканчивается на `.py`. Все остальные функции раздела будут получать адрес файла только через неё.

## Откроем каркас

Скачайте [архив урока](../../downloads/lesson-05-01-paths.zip?raw=true), распакуйте и откройте папку `lesson-05-01-paths` через **File -> Open**. Сегодняшнее задание - функция `workspace_path` в файле `workspace.py`. В папке `workspace` лежат учебный `prices.py` и тесты к нему.

## Посмотрим на данные

В `prices.py` всего одна функция:

```python
def total_price(price, quantity):
    return price + quantity
```

Стоимость заказа должна считаться умножением цены на количество, а здесь сложение. Это и предстоит исправить агенту в следующих уроках.

Путь к файлу собирается так:

```python
root = ROOT / 'workspace'
relative = 'prices.py'
candidate = (root / relative).resolve()
```

Оператор `/` у объекта `Path` соединяет папку и имя файла, а `resolve()` вычисляет полный путь: раскрывает `..` и ссылки. Проверять нужно именно полный путь. Строка `'workspace/../secret.py'` начинается с правильного имени папки, но ведёт за её пределы.

## Напишите сами

В `workspace_path` полный путь уже вычислен. Замените строку `raise NotImplementedError(...)` кодом ниже и заполните пропуск:

```python
    if Path(relative).is_absolute() or not candidate.is_relative_to(root):
        raise ValueError('Путь должен оставаться в учебной папке')
    if ...:
        raise ValueError('В упражнении работаем только с Python-файлами')
    return candidate
```

В пропуск запишите сравнение расширения: `candidate.suffix != '.py'`. Свойство `suffix` возвращает окончание имени вместе с точкой, например `'.py'`, а `!=` означает "не равно".

Первая проверка уже готова: `is_absolute()` отклоняет абсолютный путь вроде `C:\Windows\...`, а `is_relative_to(root)` проверяет, что полный путь лежит внутри рабочей папки. Если обе проверки пройдены, функция возвращает проверенный адрес. Сам файл она не открывает: читать или записывать его будет вызывающий код, и только по этому адресу.

## Запустим с моделью

Откройте `demo.py` и выберите **Run 'demo'**. Программа вызывает вашу функцию, читает разрешённый `workspace/prices.py` и просит модель предложить исправление. В Run появятся путь и предложенный код. В файл пока ничего не записывается.

## Проверим функцию отдельно

Откройте `demo_check.py` и выберите **Run 'demo_check'**. Ожидаем:

```text
workspace/prices.py
```

Для готовых проверок запустите `class LessonTests` в `tests/test_lesson.py`.

## Попробуйте сломать

В `demo_check.py` замените `'prices.py'` на `'../notes.py'` и запустите. Ожидаем ошибку "Путь должен оставаться в учебной папке". Теперь попробуйте `'tests/README.md'`: файл внутри папки, но не Python, поэтому ошибка будет другой. Верните `'prices.py'`.

## Что мы получили

Граница работы с файлами перешла из пожелания в инструкции модели в код программы. Если агент попросит чужой файл, программа откажет, как бы уверенно он ни просил.

У этой границы есть предел, о котором стоит знать администратору. Функция ограничивает, какие файлы выбирает наша программа. Если же агенту разрешено запускать код, этот код может обратиться к любому файлу, доступному пользователю. Для настоящей изоляции запуск кода выносят в отдельную среду, песочницу; в курсе мы её не строим.
