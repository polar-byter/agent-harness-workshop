# Подсказки к текущему заданию

В первом уроке мы искали заметки, записанные прямо в коде. Но рабочие сведения обычно хранятся отдельно: в файле, выгрузке или документе. Чтобы помощник использовал их, программа должна прочитать источник и подготовить данные для поиска. В этом уроке таким источником станет приложенный файл `data/notes.txt`.

Сам файл ещё не является списком заметок для Python. Между ними есть несколько действий: прочитать текст, разделить его на строки, убрать лишние пробелы и пропустить пустые строки. Соберём их в `read_notes`, чтобы поиск мог получать подготовленные строки независимо от того, как выглядит исходный текст.

Так мы увидим, как содержимое файла становится данными помощника. Это пригодится при разборе ошибки: отсутствие сведений в источнике и ошибка его чтения требуют разных исправлений. Если файл не найден, программа должна сообщить об этом, а не создать впечатление, что она прочитала его и ничего не обнаружила.

Откройте `notes.py` -> функция `read_notes`.

После разделения текста на строки в списке ещё остаются пробелы по краям заметок и пустые элементы. Внутри `read_notes` очистим каждую строку и добавим её в новый список, только если в ней что-то осталось. Для этого хватит знакомого цикла, метода `strip()` и проверки непустой строки.

Допишите уже начатую функцию по заготовке ниже, заполняя каждый `...` по подсказкам. Когда закончите, удалите строку `raise NotImplementedError(...)`; повторно добавлять заголовок `def` не нужно.

```python
def read_notes(path: Path) -> list[str]:
    text = path.read_text(encoding='utf-8')
    lines = text.splitlines()
    cleaned_notes = []
    for line in lines:
        cleaned_line = ...
        if ...:
            cleaned_notes.append(...)
    return cleaned_notes
```

В `cleaned_line` сохраните `line.strip()`: для строки `"  Первая заметка  "` получится `"Первая заметка"`, а для `" \t"` - пустая строка `""`. Затем проверьте `if cleaned_line`: в Python непустая строка считается истинной, пустая - ложной. Если условие выполнено, добавьте именно `cleaned_line` в `cleaned_notes` через `append`.

После заполнения пропусков цикл будет очищать строку, проверять её и добавлять в результат. С пустым файлом он не выполнится ни разу, поэтому функция вернёт уже созданный пустой список `[]`; отдельное условие для этого случая не требуется.

Если хочется применить list comprehension, сначала добейтесь того же поведения циклом. В короткой записи понадобятся обе части: значение `line.strip()` перед `for` и условие `if line.strip()` после него. Одна очистка без условия оставит пустые строки в списке.

Для отсутствующего файла дополнительную проверку не добавляем. Сам вызов `path.read_text(...)` остановит функцию с `FileNotFoundError`. На практике это значит: в `demo_read.py` список не будет получен, а в окне Run появится ошибка с названием отсутствующего файла. Не заменяйте её на `ValueError` или `[]`: пустой прочитанный файл и файл, которого нет, требуют разных действий.

На разобранном примере `return cleaned_notes` отдаст вызывающему коду список `['Первая заметка', 'Вторая заметка']`. Это уже отдельные очищенные строки, которые можно передать в `find_notes`, а не путь к файлу и не весь текст с переводами строк. Демонстрация только печатает полученный список; чтение и подготовку данных выполнила ваша `read_notes`.
