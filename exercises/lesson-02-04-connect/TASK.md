# Подключим настоящую модель

До сих пор программа читала готовый ответ из файла. Такой запуск помог проверить соединение функций, но не мог показать, как модель следует нашей инструкции: при другом вопросе из файла приходил тот же текст. Теперь подключим настоящую модель и проверим её на заметке о Python.

Сначала зададим вопрос, на который заметка позволяет ответить, затем спросим о том, чего в ней нет. Так мы различим два результата: программа успешно получила ответ и модель действительно ответила по источнику. Это первый опыт проверки поведения нашего помощника, а не только работоспособности кода.

Функции уже готовы. Выберите одно подключение - облачный сервис или модель на своём компьютере, - получите ответ в Run и сравните его с заметкой. Проходить все варианты не нужно. С этого момента следующие основные уроки используют сохранённое подключение.

В этом каркасе функции уже готовы. Выберите один способ подключения в уроке 2.4,
запустите configure_model.py через Run и сохраните настройки сервиса и модели.
Для локального варианта сначала установите Ollama и скачайте qwen3:0.6b.

Затем откройте demo.py и выберите Run 'demo'. Программа покажет в Run вопрос,
заметки и настоящий ответ. Сверьте его с заметкой, после чего измените только вопрос
на "Что заметки говорят о работе с файлами?". В заметке таких сведений нет,
поэтому ожидаем сообщение об их отсутствии. После опыта верните исходный вопрос.

Если нужно проверить функции отдельно от подключения, запустите demo_check.py:
он читает подготовленный ответ из файла и не подтверждает работу модели.
Настройки сохраняются вне проекта; следующие уроки прочитают их оттуда же.
Не добавляйте файл connection.json с ключом в архив или GitHub.
