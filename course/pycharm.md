# Как найти файл и запустить пример в PyCharm

Когда урок предлагает запустить файл, речь идёт о конкретном `.py`, а не обо всём проекте сразу. Для примера найдём `demo_search.py` в каркасе первого урока. В других уроках изменятся имя корневой папки и файл запуска; расположение каждого указано перед действием.

1. В открытом PyCharm выберите **View → Tool Windows → Project**. Слева появится дерево файлов. Нажмите стрелку рядом с корневой папкой `lesson-01-01-search`.
2. Найдите `demo_search.py` прямо под этой папкой: на одном уровне с `notes.py` и `start.py`, вне папок `data` и `tests`. Дважды щёлкните по нему — справа откроется код.
3. Нажмите правой кнопкой внутри открытого кода. В меню выберите **Run 'demo_search'**. Если подсказка Run предлагает другой файл, проверьте имя вкладки редактора.
4. Внизу откроется **Run**. Там появятся сообщения этого запуска. Если окно скрыто, откройте **View → Tool Windows → Run**.

<img src="../assets/common/pycharm-run.png" width="570" alt="pycharm-run">

Это поясняющая схема, не снимок вашей версии PyCharm. Внизу изображён ожидаемый результат уже реализованного поиска; до реализации появится сообщение о незаполненной функции. Названия пунктов могут отличаться при другой локализации. Общий способ запуска файла описан в [документации PyCharm](https://www.jetbrains.com/help/pycharm/running-without-any-previous-configuring.html).

Если файла нет в дереве, проверьте название открытой папки: оно должно совпадать с указанным в уроке. У каждого урока теперь собственный архив. Распакуйте его и откройте через **File → Open** именно внутреннюю папку `lesson-…`, а не ZIP и не папку `tests`. Создавать недостающий демонстрационный файл вручную не требуется.

Верхняя кнопка запуска повторяет выбранную конфигурацию, то есть может запустить прежний файл. Пока надёжнее выбирать Run из контекстного меню нужного открытого файла.
