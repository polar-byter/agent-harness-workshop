# Урок 4. Соединяем чтение, поиск и журнал

[Открыть исходники этого урока](../../exercises/lesson-01-04-run/README.md) / [Подсказки рядом с кодом](../../exercises/lesson-01-04-run/TASK.md)

Теперь у нас есть чтение заметок из файла, поиск строк и сохранение результата. Пока это три отдельных возможности. Чтобы помощник мог пользоваться поиском, программе нужен законченный порядок действий: прочитать источник, отобрать заметки и записать, что получилось.

Соберём этот порядок в `run_search`. Один вызов даст словарь с запросом, статусом и найденными строками, а в журнале останется такая же запись. Если чтение не удалось или запрос пуст, выполнение остановится до сохранения успешного результата.

Эта практика показывает, как из небольших функций получается операция, которую можно подключить к другой программе. Позднее агент будет запрашивать поиск, а чтение и запись останутся обязанностью нашего кода. У нас появится понятное место для проверки: что операция получила, что вернула и что сохранила.

## Посмотрим на данные

В `demo.py` уже указаны файл заметок, запрос `"Python"` и путь к журналу. Функция `run_search` получит эти три значения и вернёт словарь с запросом, найденными строками и статусом: `found`, если строки нашлись, или `not_found`, если список пуст. Если файл не удалось прочитать, до записи результата дело не должно дойти: ошибку чтения нельзя выдавать за поиск без совпадений.

```python
matches = ['Python lists']
status = 'found' if matches else 'not_found'
# Для [] получится 'not_found'.
```

Этот пример нужен для разбора; в функцию его переносить не нужно, поскольку вызов с исходными данными уже подготовлен в `demo.py`.

## Соберём функцию с подсказками

В каркасе уже стоят два первых вызова: `read_notes` читает строки из файла, а `find_notes` отбирает из них подходящие. Из списка `matches` определим статус, соберём словарь результата и передадим его в `write_result` для сохранения. Тот же словарь вернём в `demo.py`, чтобы увидеть его в Run.

Допишите уже начатую функцию по заготовке ниже, заполняя каждый `...` по подсказкам. Когда закончите, удалите строку `raise NotImplementedError(...)`; повторно добавлять заголовок `def` не нужно.

```python
def run_search(notes_path: Path, query: str, journal_path: Path) -> dict:
    notes = read_notes(notes_path)
    matches = find_notes(notes, query)
    status = 'found' if matches else 'not_found'
    result = {
        'query': ...,
        'status': ...,
        'matches': ...,
    }
    write_result(..., ...)
    return result
```

В поле `query` положите `query.strip()`, в `status` - уже вычисленную переменную `status`, в `matches` - список `matches`. Кавычки здесь обозначают имена полей словаря; значения справа могут быть переменными. Например, `result["matches"]` затем вернёт найденные строки.

Вызов `write_result` получает сначала `journal_path`, затем `result`. Расположите его после чтения и поиска: если файл не найден или запрос пуст, до сохранения дело не дойдёт. В конце `return result` передаст словарь в `demo.py`, который его напечатает.

## Найдём файл запуска и проверим результат

В левой панели **Project -> lesson-01-04-run -> demo.py** откройте файл двойным щелчком. Нажмите правой кнопкой внутри открытого редактора и выберите **Run 'demo'**. Внизу появится окно **Run** с выводом именно этого файла. Отдельная общая кнопка "запустить проект" нам здесь не нужна: выбираем конкретный демонстрационный файл. Если панель с файлами скрыта, вернитесь к **View -> Tool Windows -> Project**. Если Run скрыто - **View -> Tool Windows -> Run**.

До завершения функции появится сообщение "Допишите ... по подсказкам урока". После реализации ожидаем:

```text
{'query': 'Python', 'status': 'found', 'matches': ['Python functions return values.', 'Python lists keep item order.']}
```

Для дополнительного контроля откройте в этом же проекте `tests/test_lesson.py`, найдите `class LessonTests`, нажмите правой кнопкой по имени класса и выберите Run. Это необязательная проверка текущего задания; внутреннее устройство тестов сейчас разбирать не нужно.
