## В чем опасность относительных путей?

Если модель сгенерирует путь: `../../../../Windows/System32` или `../../private/passwords.txt`, наивная программа может прочитать или перезаписать конфиденциальные системные файлы.

В модуле `workspace.py` мы реализуем строгую валидацию путей через `pathlib.Path`:

```python
def safe_path(root: Path, relative: str) -> Path:
    target = (root / relative).resolve()
    if not target.is_relative_to(root.resolve()):
        raise PermissionError(f"Выход за пределы рабочей папки запрещен: {relative}")
    return target
```

* `.resolve()` раскрывает все точки `..` и вычисляет абсолютный путь.
* `.is_relative_to(root)` проверяет: находится ли путь строго внутри папки проекта.
