# Подсказки к текущему заданию

> **Где мы.** Агент предложил правку, человек её одобрил, программа записала файл. Последний шаг: убедиться, что код после правки действительно работает.
> `предложение -> diff -> согласие -> запись -> [тесты]`

Пока мы знаем только, что изменение записано. Это не значит, что расчёт стоимости заказа стал правильным: модель могла предложить код с другой ошибкой, а человек мог её не заметить в diff. Проверять нужно поведение кода: при цене 100 и количестве 3 стоимость должна быть 300.

Для этого в папке `workspace/tests` лежат тесты расчёта. Функция `check_project` запустит их из нашей программы и вернёт понятный отчёт. На исходном сложении тесты не пройдут, после правильного исправления пройдут. Важная деталь: условия проверки задали мы заранее, а не модель после своей правки.

Откройте `workspace.py` -> функция `check_project`.

## Напишите сами

Замените в `check_project` строку `raise NotImplementedError(...)` кодом ниже и заполните пропуски:

```python
    process = subprocess.run(
        command,
        cwd=root,
        capture_output=True,
        text=True,
        encoding='utf-8',
        errors='replace',
        timeout=5,
    )
    return {
        'passed': ...,
        'returncode': process.returncode,
        'output': ...,
    }
```

1. В `'passed'` запишите `process.returncode == 0`.
2. В `'output'` - `process.stdout + process.stderr`: тесты пишут сообщения в оба потока.

`subprocess.run` запускает процесс и ждёт его завершения. `cwd=root` - папка, из которой запускаются тесты, `capture_output=True` собирает вывод вместо печати на экран, `text=True` и `encoding` возвращают его строками, `timeout=5` не даёт ждать дольше пяти секунд, если тесты зависли.

## Запустим с моделью

Откройте `demo.py` и выберите **Run 'demo'**. Теперь работает весь проход: модель предлагает исправление, программа показывает diff, спрашивает согласие, записывает правку и запускает вашу функцию. Введите `да`, если согласны с правкой, или нажмите Enter для отказа. В Run появится результат тестов для текущего `prices.py`.

**Угадайте до запуска:** что покажут тесты, если вы откажетесь от правки?

## Проверим функцию отдельно

Откройте `demo_check.py` и выберите **Run 'demo_check'**. Он запускает тесты для текущего `workspace/prices.py` без модели. В только что распакованном архиве там сложение, поэтому ожидаем `passed: False`, ненулевой `returncode` и в `output` сообщение теста: ожидалось 300, получено 103. Если вы уже применили правильную правку через `demo.py`, результат будет `passed: True`. Для готовых проверок запустите `class LessonTests`.

## Попробуйте сломать

Откройте `workspace/prices.py` и вручную замените расчёт на `return price * quantity + 1`. Запустите `demo_check.py`. Тесты не пройдут, и в `output` будет видно, какое значение ожидалось и какое получилось. Именно так выглядит правка, которая записана, но неверна. Затем исправьте строку на `return price * quantity` и запустите снова: теперь `passed: True`. Чтобы повторить весь проход с моделью, верните исходный текст `return price + quantity`.
