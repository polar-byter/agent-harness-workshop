# Для кого эти уроки

Курс рассчитан на аналитиков, руководителей и владельцев процессов, системных администраторов, специалистов поддержки и тестировщиков - на всех, кто внедряет ИИ-помощников, принимает их работу или отвечает за участок, где они появились. Чем каждому из них полезно понимание устройства агента, разобрано во [введении](00-introduction.md).

Программистом быть не нужно. Достаточно уверенно пользоваться компьютером и быть готовым читать короткие фрагменты кода. Python мы осваиваем по ходу дела, ровно в том объёме, который нужен текущему шагу: строки, списки, словари, циклы, функции и чтение файлов. Эти же навыки пригодятся и вне курса, когда нужно сверить две выгрузки или собрать отчёт из нескольких файлов.

## Что понадобится

- Компьютер с Windows. Уроки показывают путь именно для Windows и PyCharm.
- PyCharm и Python 3.12 или новее. Как их установить и открыть первый проект, рассказано в [подготовке](01-note-search/00-setup.md).
- С урока 2.4 - подключение к модели. Можно выбрать облачный сервис по API или запустить небольшую модель Qwen прямо на ноутбуке через Ollama, без регистрации и оплаты.

## Как устроен каждый урок

У каждого урока свой архив с готовым проектом. Всё, что написано в прошлых уроках, в нём уже работает, а текущая функция начата и остановлена на строке `raise NotImplementedError(...)`. В уроке показаны данные, с которыми работает функция, и заготовка с пропусками `...`, к каждому пропуску есть подсказка. Вы дописываете функцию, запускаете пример и сравниваете результат с ожидаемым. Готовые тесты в папке `tests` позволяют дополнительно проверить решение.

Архивы независимы: если какой-то урок не получился, можно открыть архив следующего и продолжить с него. Через весь курс проходит один пример - регламент возвратов интернет-магазина, по которому помощник отвечает на вопросы клиентов.

Начать можно с [введения](00-introduction.md) или сразу с [открытия первого проекта](01-note-search/00-setup.md). Весь маршрут собран в [оглавлении курса](README.md).
