# Подсказки к текущему заданию

> **Где мы.** Третий урок дополнительного учебника. Сообщения мы умеем готовить, ответ умеем разбирать. Между ними - сама отправка запроса сервису модели.
> `сообщения -> [HTTP-запрос -> ответ] -> текст -> команда`

И к Ollama, и к облачному сервису наша программа обращается по HTTP. С Ollama обмен идёт внутри компьютера, с облачным сервисом - через интернет. Готовая `send_live` в `transport.py` выбирает адрес, собирает словарь с именем модели и сообщениями и поручает отправку функции `request_json`. Её сетевую часть мы и напишем.

Это поможет различать два вида неполадок: запрос вообще не дошёл до сервиса или ответ пришёл, но не в том виде, которого ждёт программа. Сначала проверим код на известных данных без сети, затем через сохранённое подключение.

Откройте `transport.py` -> функция `request_json`.

## Напишите сами

Код состоит из двух фрагментов. Первый вставьте на место строки `raise NotImplementedError(...)`, с отступом функции:

```python
request = Request(
    url,
    data=...,
    headers=headers,
    method='POST',
)
```

Второй замените на место строки `pass` внутри готового блока `try`, на один уровень отступа глубже `try`:

```python
with urlopen(request, timeout=180) as response:
    text = ...
    return ...
```

1. В `data=` - `json.dumps(payload, ensure_ascii=False).encode('utf-8')`: словарь становится строкой JSON, а `encode` превращает её в байты для передачи.
2. В `text` - `response.read().decode('utf-8')`: `read()` получает байты ответа, `decode` делает из них текст.
3. В `return` - `json.loads(text)`: текст JSON снова становится словарём.

`Request` только описывает запрос, отправляет его `urlopen`. Блок `with ... as response` закроет соединение после выхода. `timeout=180` - сколько секунд ждать отдельную сетевую операцию. Готовые обработчики ошибок различают ответ с кодом ошибки и отсутствие соединения: например, HTTP 401 превращается в подсказку проверить API-ключ.

На проверочном ответе байты `b'{"ok": true}'` станут строкой `'{"ok": true}'`, а затем словарём `{'ok': True}`. В настоящем запуске этот словарь получит `send_live`, проверит, что ответ завершён, и достанет из него текст.

## Сначала проверим обмен данными

Откройте `demo_check.py` и выберите **Run**. После реализации в Run появятся `POST`, адрес `https://example.invalid/chat`, исходные данные запроса и результат `{'ok': True}`. Для готовых проверок запустите `tests/test_lesson.py`.

Затем запустите `demo.py`. Он делает настоящий запрос через сохранённое подключение: задаёт вопрос "Сколько дней есть на возврат товара?" и передаёт пункт "Возврат товара возможен в течение 14 дней." Здесь модель просто отвечает по пункту, без выбора инструментов: для проверки сетевой функции этого достаточно. Ждём ответ про 14 дней, точные слова зависят от модели. У облачного сервиса запрос расходует квоту.
