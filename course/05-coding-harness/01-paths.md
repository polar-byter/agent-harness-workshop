# Урок 1. Ограничиваем рабочую папку

[Открыть исходники этого урока](../../exercises/lesson-05-01-paths/README.md) / [Подсказки рядом с кодом](../../exercises/lesson-05-01-paths/TASK.md)

Теперь помощник будет предлагать изменение Python-файла. Для опыта подготовлена папка `workspace` с расчётом цены и тестами. Прежде чем читать или менять исходник по предложению модели, программе нужно определить, с какими файлами вообще разрешено работать.

Например, имя `prices.py` относится к нашей учебной папке, а `../outside.py` указывает на попытку выйти за её пределы. В `workspace_path` получим полный путь, проверим принадлежность папке и разрешённое расширение. Остальные функции будут получать адрес через эту проверку.

Так мы перенесём границу работы с файлами из пожелания в инструкциях модели в код приложения. Станет видно, где именно отклоняется неподходящий путь и почему одной просьбы "работай только здесь" недостаточно. Эта функция ограничивает выбор файлов нашим приложением; выполнение Python-кода будем рассматривать отдельно.

## Посмотрим на данные

В `demo.py` переменная `root` указывает на учебную папку `workspace`. В параметр `relative` передадим имя `"prices.py"` и захотим получить полный путь к этому файлу. Для другого имени проверка должна убедиться, что путь по-прежнему остаётся внутри `workspace` и оканчивается на `.py`.

```python
root = ROOT / 'workspace'
relative = 'prices.py'
candidate = (root / relative).resolve()
```

Оператор `/` у объекта `Path` соединяет папку и имя файла, а `resolve()` получает полный путь. Проверять будем именно его: текст с `..` или ссылка могут привести за пределы папки. Это ограничение выбора файлов в нашем приложении; само по себе оно не изолирует выполняемый Python-код от операционной системы.

## Соберём функцию с подсказками

Прежде чем читать или менять файл, нужно убедиться, что предложенный путь относится к учебной папке. Одного совпадения начала строки недостаточно: путь может содержать `..` или вести через ссылку в другое место. Поэтому сначала получим полный путь, а затем проверим его средствами `Path`.

Допишите уже начатую функцию по заготовке ниже, заполняя каждый `...` по подсказкам. Когда закончите, удалите строку `raise NotImplementedError(...)`; повторно добавлять заголовок `def` не нужно.

```python
def workspace_path(root: Path, relative: str) -> Path:
    root = root.resolve()
    candidate = (root / relative).resolve()
    if Path(relative).is_absolute() or not candidate.is_relative_to(root):
        raise ValueError('Путь должен оставаться в учебной папке')
    if ...:
        raise ValueError('В упражнении работаем только с Python-файлами')
    return candidate
```

Первую проверку пути оставим готовой. В пропуске нужно сравнить расширение: `candidate.suffix != ".py"`. Свойство `suffix` возвращает последнюю часть имени с точкой, например `".py"`. Знак `!=` означает "не равно".

`root / relative` соединяет части пути, `resolve()` вычисляет полный путь, `is_absolute()` распознаёт абсолютный путь, а `is_relative_to(root)` проверяет принадлежность корню. На разрешённом `"prices.py"` функция вернёт путь; на `"../outside.py"` остановится с ошибкой. Это граница выбора файлов нашего приложения, а не защита от любых действий исполняемого кода.

Вызов `path = workspace_path(ROOT / 'workspace', 'prices.py')` отдаст программе объект `Path`, указывающий на `workspace/prices.py` внутри папки этого каркаса. Это проверенный адрес файла: вызывающий код сможет прочитать его содержимое или записать изменение. Сам `return candidate` файл не открывает и не меняет. Если предложен выход из папки, функция вместо адреса выдаёт ошибку, поэтому дальнейшее действие по этому пути не должно начаться.

## Запустим с нашей моделью

После реализации откройте **Project -> lesson-05-01-paths -> demo.py**, щёлкните правой кнопкой внутри редактора и выберите **Run 'demo'**. Результат появится в панели **Run**; её можно открыть через **View -> Tool Windows -> Run**.

Программа сначала вызывает вашу функцию `workspace_path`, а затем читает разрешённый `workspace/prices.py` и просит подключённую модель предложить исправление. В Run появятся путь и предложенный код. Записи в файл пока нет. Сам выбор допустимого пути проверим отдельно на запрещённых значениях: корректный ответ модели не доказывает надёжность этой границы.

Если настройки ещё не сохранены или перестали работать, вернитесь к [уроку подключения модели](../02-note-assistant/04-connect.md). В этом запуске модель не подменяется ответом из файла. Маленькая локальная модель может плохо соблюдать формат JSON; сначала отличите ошибку разбора её ответа от ошибки вашей функции. Если подключение работает, но возможностей модели не хватает, смените модель через `configure_model.py`, сохранив реализацию задания.
