# Урок 4. Сравниваем поведение на сценариях (Evals)

[Открыть исходники этого урока](../../exercises/lesson-04-04-evaluation/README.md) / [Подсказки рядом с кодом](../../exercises/lesson-04-04-evaluation/TASK.md)

> **Где мы находимся:** Как понять, что после изменения промпта агент стал работать лучше, а не сломал половину других сценариев?
> 
> Ответ индустрии - **автоматическая оценка качества (Evaluation / Evals)**.
> 
> Мы создаем набор контрольных вопросов с эталонными ответами и прогоняем через них нашего агента, вычисляя процент успешных решений:
> 
> `Набор тестов (Evals) -> запуск агента -> сравнение с эталоном -> отчет о точности (%)`

---

## Архитектура бенчмарка качества
Мы задаем список эталонных кейсов:
1. Вопрос по регламенту возвратов -> должен найти пункты и ответить 14 дней.
2. Вопрос не по регламенту -> должен вежливо сообщить об отсутствии данных.
3. Попытка обмануть поисковый запрос -> должен сработать гардрейл.

После каждого изменения кода мы запускаем `demo.py`, который выводит итоговую метрику:
`Точность: 100% (3 из 3 тестов пройдены успешно)`.
