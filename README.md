# Агентная мастерская

Курс о том, как устроены ИИ-агенты и как проверять их работу. Через весь курс проходит один пример: помощник отвечает клиентам интернет-магазина по регламенту возвратов. Шаг за шагом мы пишем на Python поиск по регламенту, подключаем модель, даём ей инструменты, ограничиваем её действия, ведём журнал и в конце собираем небольшого агента, который предлагает правку кода и применяет её только с согласия человека.

Курс рассчитан на аналитиков, руководителей и владельцев процессов, администраторов, специалистов поддержки и тестирования. Знать Python заранее не нужно: в каждом уроке есть задача на конкретных данных, начатая функция и подсказки к пропускам.

**[Начать с введения](course/00-introduction.md)** / **[Для кого этот курс](course/who-this-is-for.md)** / **[Все уроки](course/README.md)** / **[Итоги и применение](course/conclusion.md)**

Если хочется самому написать готовые части `decisions.py` и `transport.py`, есть [дополнительный учебник](course/extra-prepared-modules/README.md) из четырёх уроков с каркасами.

## Как здесь учиться

Откройте [подготовку первого проекта](course/01-note-search/00-setup.md). Уроки можно читать прямо на GitHub: схемы, анимации и примеры лежат рядом с текстом. Для практики скачайте архив нужного урока по ссылке в статье и откройте распакованную папку в PyCharm.

Можно скачать и всё сразу: выберите на этой странице **Code -> Download ZIP**, распакуйте репозиторий и откройте в PyCharm нужную папку внутри `exercises`, например `exercises/lesson-01-01-search`, а не весь репозиторий.

У каждого урока свой каркас: всё, что написано раньше, уже работает, текущую функцию предстоит дописать. Что сделать, объяснено в статье и в `TASK.md` рядом с кодом, поэтому курс можно проходить подряд или вернуться к отдельной теме.

## Что понадобится

Для начала достаточно Python 3.12 или новее и PyCharm. Каркасы используют стандартную библиотеку. Второй подпроект завершается [подключением настоящей модели](course/02-note-assistant/04-connect.md): через OpenRouter, VseGPT или локальную Ollama. В следующих подпроектах основной `demo.py` использует это подключение, а `demo_check.py` проверяет код на фиксированных данных без обращения к модели.

Проверки сборки репозитория проверяют материалы и запуск каркасов. Тесты написанного вами решения запускаются отдельно после упражнения - этот шаг объясняется в уроках.
