# Собираем decide_live из знакомых функций

[Открыть исходники этого урока](../../exercises/lesson-extra-04-decision/README.md) / [Подсказки рядом с кодом](../../exercises/lesson-extra-04-decision/TASK.md)

> **Где мы.** Последний урок дополнительного учебника. Все части готовы: сообщения, отправка, разбор ответа. Соберём из них функцию, которая в основном курсе была готова заранее.
> `задача + история -> [сообщения -> send_live -> текст -> команда]`

Чтобы узнать следующий шаг агента, программа передаёт модели правила, задачу и результаты прежних действий, получает ответ и читает из него команду. Выполнять ли команду, решает уже другая часть программы.

Соединим эти действия в `decide_live` из `decisions.py`: `build_decision_messages` подготовит сообщения, `send_live` получит ответ, `extract_answer` достанет текст, а `parse_decision` - словарь команды. Сама `decide_live` делает одно обращение за решением, без выполнения поиска и без цикла. Когда весь этот участок перед глазами, легко проверить, что ушло к модели, что она вернула и на каком этапе возникла ошибка.

## Проследим один запрос

В `demo_check.py` задача "Найди в регламенте пункты о возврате" передаётся с пустой историей: это первое обращение, поиска ещё не было. Вместо модели проверочный запуск возвращает подготовленный ответ с текстом команды:

```json
{"type":"tool","tool":"find_notes","query":"возврат"}
```

Ollama и облачные сервисы присылают ответы разной формы, а `send_live` приводит их к общему формату курса. Для нашего примера он выглядит так:

```python
response = {'status': 'completed', 'output': [
    {'type': 'message', 'content': [
        {'type': 'output_text',
         'text': '{"type":"tool","tool":"find_notes","query":"возврат"}'}
    ]}
]}
```

Внешний словарь описывает завершённый ответ сервиса, а в поле `text` лежит сама команда модели. `extract_answer` достаёт эту строку, `parse_decision` превращает её в словарь, и вызывающий код получает `{'type': 'tool', 'tool': 'find_notes', 'query': 'возврат'}` - команду, а не описание ответа сервиса.

## Напишите сами

Замените заглушку в `decide_live` кодом ниже и заполните четыре пропуска:

```python
def decide_live(task: str, events: list[dict]) -> dict:
    messages = ...
    response = ...
    text = ...
    return ...
```

1. `messages` - результат `build_decision_messages(task, events)`.
2. `response` - результат `send_live(messages)`.
3. `text` - результат `extract_answer(response)`.
4. Верните `parse_decision(text)`.

Имена переменных помогают не перепутать этапы: `messages` - список сообщений до запроса, `response` - словарь ответа в общем формате, `text` - строка JSON внутри него. Словарём команды становится только результат последней строки.

## Сравним проверочный ответ с настоящим

Откройте `demo_check.py` и выберите **Run**. После реализации в Run появится словарь с запросом "возврат". Для готовых проверок запустите `tests/test_lesson.py`.

Затем запустите `demo.py`. Он выводит выбранную модель и задачу (ключ API не печатается) и делает настоящий запрос. Модель может выбрать `find_notes`, `read_notes` или сразу ответить. Если вместо JSON пришла обычная фраза, сработает проверка в `parse_decision`. А правильный JSON ещё не значит, что действие выбрано удачно: это видно только по самой команде.

Демонстрация печатает словарь и ничего не выполняет. В основном курсе словарь дальше попадает в `dispatch_tool`, которая проверяет название инструмента и выполняет разрешённое действие. Путь к файлу регламента задаёт программа, в команде модели его нет.

## Где здесь продолжается агентный цикл

После выполнения инструмента `run_agent` добавляет результат в `events` и снова вызывает `decide_live` с той же задачей. Функция заново собирает сообщения, поэтому модель получает уже дополненную историю и решает, нужен ли ещё инструмент или пора отвечать. Так `decide_live` делает один запрос за решением, а повторением шагов управляет `run_agent`.

Откройте `decisions.py` в каркасе [основного урока с инструментами](../03-tool-agent/01-tools.md). Там те же операции собраны в одной функции: правила и сообщения, `send_live`, `extract_answer`, `json.loads` и проверка словаря. Сопоставьте их со своими четырьмя строками. Копировать файлы из дополнительной практики в основной маршрут не нужно. Вернуться к [оглавлению](../README.md).
