> **Где мы находимся:** Самый главный урок курса по устройству автономных агентов!
> 
> Мы собираем **агентный цикл (Agentic Loop)** - бесконечный цикл взаимодействия, где модель анализирует задачу, запрашивает инструмент, программа выполняет его и возвращает результат обратно модели, пока задача не будет полностью решена:
> 
> `Задача -> [Модель решает шаг] -> Команда -> [dispatch_tool] -> Результат в историю -> [Повтор] -> Финальный ответ`

---

## Как устроен классический агентный цикл?

Агент отличается от простого чат-бота тем, что может выполнять **многошаговые цепочки рассуждений и действий**:

1. **Шаг 1:** Модель смотрит на задачу: *"Клиент спрашивает о сроке возврата"*. Решает: *"Мне не хватает данных. Запрашиваю инструмент search с запросом 'срок возврата'"*.
2. **Шаг 2:** Наша программа выполняет поиск и возвращает строку: *"Возврат товара возможен в течение 14 дней"*.
3. **Шаг 3:** Модель смотрит на историю и понимает: *"Теперь у меня есть точный ответ. Инструменты больше не нужны. Возвращаю финальный ответ клиенту"*.
4. **Шаг 4:** Цикл завершается!

### Защита от бесконечного цикла: лимит шагов (Budget Guardrail)
Что произойдет, если модель зациклится и начнет вызывать поиск бесконечно? Ваш сервер зависнет, а баланс API обнулится за пару минут.
Поэтому агентный цикл **обязан** иметь жесткий предохранитель: параметр `max_steps` (например, 5 шагов). Если лимит исчерпан, цикл принудительно останавливается.
