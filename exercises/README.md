# Исходники упражнений

Здесь можно открыть код каждого каркаса прямо на GitHub. Для практики скачайте архив из урока или весь репозиторий через Code -> Download ZIP и откройте нужную папку в PyCharm.

Внутри каждой папки: `README.md` с запуском, `TASK.md` с подсказками, текущие модули, `demo.py`, данные и проверки. В уроках реализации текущие функции намеренно недописаны. В уроке подключения функции уже готовы: нужно настроить модель и проверить настоящий ответ. Начиная с третьего подпроекта `demo.py` использует сохранённое подключение, а `demo_check.py` служит отдельной проверкой без модели.
