# Подготовка. Откроем проект и сделаем первый запуск

В [начале курса](../00-introduction.md) мы разобрали, почему готовый ChatGPT уже умеет работать с переданными документами, а нам всё же полезно построить собственную систему. Теперь у этой идеи появится первая практическая задача — поиск по небольшому набору заметок.

Допустим, у нас есть три заметки:

```text
Python lists
Agent tools
python functions
```

Мы передадим программе слово `'python'` и захотим получить первую и третью строки: `'Python lists'` и `'python functions'`. Вторая заметка не содержит этого слова. Когда поиск заработает, научим программу читать заметки из файла и сохранять результат запуска.

## Что должно получиться

Первый результат — небольшой поиск, который получает запрос и возвращает подходящие заметки. Затем научим его читать данные из файла и сохранять результат запуска. Эти части мы сможем проверить по отдельности, прежде чем подключать их к модели.

Общий путь к агентному циклу и работе с учебным кодом описан во [введении](../00-introduction.md). Здесь сосредоточимся на первом проекте и подготовим среду, в которой удобно его писать.

## Проследим запрос от ввода до результата

Посмотрим на работу будущей программы. После завершения первого проекта ей можно будет передать `'python'` и набор заметок. Поиск отберёт подходящие строки, а приложение покажет их пользователю:

```text
Запрос «python» + заметки → поиск → две найденные заметки
```

В проекте эта работа распределена между несколькими файлами. В `notes.py` научим программу читать и искать заметки, `app.py` соединит её действия, а `journal.py` сохранит результат. Сразу писать все три не потребуется: в первом уроке займёмся только поиском.

Зачем мы вообще начинаем с обычной функции, если курс об агентах? Позднее модель сможет решить, что ей нужен поиск, и вызвать наш инструмент. А внутри инструмента будет работать уже знакомый нам код. Так мы сможем понять, где ошиблась сама программа, а где — решение модели.

В каркасе есть и папка `tests` с готовыми проверками. Здесь мы позаимствуем у программистов практику юнит-тестирования: для отдельной функции задают входные данные и ожидаемый результат, а программа сравнивает его с фактическим. Такие проверки помогают сохранять нужное поведение при изменении кода. Сейчас читать их устройство не требуется; после первого работающего поиска я предложу необязательный разбор.

## Откроем рабочую папку в PyCharm

Для этого маршрута я выбрал Windows и PyCharm — программу, в которой удобно редактировать и запускать Python-код. Если PyCharm ещё не установлен, скачайте его с [сайта JetBrains](https://www.jetbrains.com/pycharm/download/) и установите. Для наших упражнений достаточно бесплатных возможностей.

Кроме редактора понадобится сам Python: именно он выполняет код. Если Python ещё не установлен, возьмите установщик для Windows с [официального сайта](https://www.python.org/downloads/windows/) и завершите установку. Для этого проекта подходит Python 3.12 или новее. Если Python уже есть, повторно устанавливать его не нужно.

Теперь скачайте [каркас первого урока](../../downloads/lesson-01-01-search.zip?raw=true) и распакуйте архив через «Извлечь всё». Внутри находится папка `lesson-01-01-search`. На стартовом экране PyCharm нажмите **Open** и выберите именно её. Если редактор уже открыт, используйте **File → Open**.

Откройте **View → Tool Windows → Project**: слева появится дерево файлов. Разверните стрелкой корневую папку `lesson-01-01-search`. Прямо в ней, рядом с `notes.py`, найдите `start.py` и откройте двойным щелчком: это подготовленный файл, который выводит короткое сообщение и помогает проверить запуск Python. Он ещё не выполняет поиск — эту часть мы напишем в следующем уроке. Код в `start.py` менять не требуется.

## Выберем Python в редакторе

Для открытого проекта PyCharm должен знать, какой установленный Python использовать. Откройте **File → Settings → Python → Interpreter**. Если там уже выбран Python подходящей версии, оставьте его и переходите к запуску.

Если интерпретатор не выбран, нажмите **Add Interpreter → Add Local Interpreter**, выберите **Virtualenv** и укажите установленный Python в поле **Base interpreter**. Место для окружения оставьте предложенное редактором и подтвердите настройку. Окружение — это отдельное место для библиотек проекта; пока устанавливать в него ничего не понадобится. Названия пунктов могут немного отличаться между версиями PyCharm; ориентиром служит [официальная инструкция по настройке](https://www.jetbrains.com/help/pycharm/configuring-python-interpreter.html).

## Сделаем первый запуск

В панели **Project → lesson-01-01-search → start.py** откройте файл двойным щелчком, нажмите правой кнопкой внутри редактора и выберите **Run 'start'**. Внизу откроется окно запуска. В нём должна появиться строка:

```text
Проект открыт. Python работает.
```

Мы запустили подготовленный `start.py` и увидели его сообщение. Значит, редактор нашёл Python и смог выполнить файл проекта. Теперь можно перейти к [первому уроку](01-search.md) и написать сам поиск.

Если PyCharm сообщает, что Python не выбран, вернитесь к настройке интерпретатора выше. Если кнопки Run нет, проверьте, что открыт файл `start.py` из распакованной папки, а не сам ZIP-архив. Для этого шага терминал не нужен.

Если пока трудно ориентироваться в окнах, посмотрите [схему поиска файла и запуска в PyCharm](../pycharm.md).
