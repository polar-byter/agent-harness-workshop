# Как найти файл и запустить пример в PyCharm

Когда урок предлагает запустить файл, речь идёт о конкретном `.py`, а не обо всём проекте. Для примера найдём `demo_search.py` в каркасе первого урока; в других уроках меняются только имя папки и имя файла, и они всегда указаны в тексте.

1. В PyCharm выберите **View -> Tool Windows -> Project**. Слева появится дерево файлов. Нажмите стрелку рядом с корневой папкой `lesson-01-01-search`.
2. Найдите `demo_search.py` прямо под этой папкой, рядом с `notes.py` и `start.py`, а не внутри `data` или `tests`. Откройте его двойным щелчком.
3. Нажмите правой кнопкой внутри открытого кода и выберите **Run 'demo_search'**. Если в меню предлагается другой файл, проверьте имя вкладки редактора.
4. Внизу откроется окно **Run** с сообщениями этого запуска. Если его не видно, выберите **View -> Tool Windows -> Run**.

<img src="../assets/common/pycharm-run.png" width="570" alt="pycharm-run">

На схеме внизу показан результат уже написанного поиска; пока функция не дописана, в Run будет сообщение "Допишите find_notes по подсказкам урока". Названия пунктов меню могут немного отличаться в другой версии или локализации. Общий способ запуска файла описан в [документации PyCharm](https://www.jetbrains.com/help/pycharm/running-without-any-previous-configuring.html).

Если нужного файла нет в дереве, проверьте, какая папка открыта. Распакуйте архив урока и откройте через **File -> Open** именно внутреннюю папку `lesson-...`, а не ZIP-файл и не папку `tests`.

Зелёная кнопка запуска вверху окна повторяет последнюю конфигурацию и может запустить не тот файл. Надёжнее выбирать **Run** из контекстного меню в нужном открытом файле.
