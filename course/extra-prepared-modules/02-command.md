# Как получить команду из текста

[Открыть исходники этого урока](../../exercises/lesson-extra-02-command/README.md) / [Подсказки рядом с кодом](../../exercises/lesson-extra-02-command/TASK.md)

> **Где мы.** Второй урок дополнительного учебника. Сообщения для модели готовы. Теперь научимся читать её ответ.
> `сообщения -> модель -> [текст -> словарь команды] -> dispatch_tool`

Модель ответила `{"type":"tool","tool":"find_notes","query":"возврат"}`. Нам понятно, что это просьба о поиске. Для Python это пока одна строка, из которой ещё нужно достать отдельные значения.

А ещё модель может ответить "Сейчас поищу" или прислать JSON-список вместо объекта. Программа не должна принимать такой ответ за команду и работать дальше с отсутствующими данными. Поэтому `parse_decision` разберёт текст, проверит, что получился словарь, и либо вернёт его, либо сообщит об ошибке. Здесь заканчивается ответ модели и начинается ответственность нашего кода.

## Как текст превращается в данные программы

В `demo_check.py` подготовлен такой ответ:

```python
text = '{"type":"tool","tool":"find_notes","query":"возврат"}'
```

Глазами мы видим в строке слова `tool` и `query`, но полей с такими именами у строки нет. Чтобы до них добраться, разберём текст функцией `json.loads`:

```python
command = json.loads(text)
command['tool']    # 'find_notes'
command['query']   # 'возврат'
```

Теперь `command` - словарь: по ключу `'tool'` лежит `'find_notes'`, по ключу `'query'` - `'возврат'`. `json.loads` ничего не выбирает и не придумывает, она только читает то, что записано в тексте. Запомнить пару легко: `dumps` превращает данные в текст, `loads` - текст в данные.

## Почему после разбора нужна проверка

Если модель ответила обычной фразой "Сейчас поищу", `json.loads` выдаст ошибку `JSONDecodeError`. А строка `'[]'` - правильный JSON, но после разбора получится список, а команде нужен словарь. Оба случая обработаем отдельно.

## Напишите сами

Замените заглушку в `parse_decision` кодом ниже и заполните два пропуска:

```python
def parse_decision(text: str) -> dict:
    try:
        command = ...
    except json.JSONDecodeError:
        raise ValueError('Модель вернула текст вместо команды JSON: ' + text[:400]) from None
    if not isinstance(command, ...):
        raise ValueError('Команда должна быть объектом JSON')
    return command
```

1. В `command` - результат `json.loads(text)`.
2. В `isinstance` - тип `dict`.

Блок `try` содержит действие, которое может закончиться ошибкой. Если это `JSONDecodeError`, Python переходит к `except`, и мы заменяем техническое сообщение понятным. `text[:400]` берёт первые 400 символов ответа, чтобы не печатать длинный текст целиком. `isinstance(command, dict)` вернёт `True` для словаря и `False`, например, для списка.

Функция возвращает словарь тому, кто её вызвал. В демонстрации это строка `decision = parse_decision(text)`, после которой `decision['tool']` даёт `'find_notes'`. Поиск при этом не запускается: команду выполнит `dispatch_tool` в основном проекте.

## Проверим три разных ответа

Откройте `demo_check.py` и выберите **Run**. Сначала увидим переход от строки к словарю:

```text
До разбора: <class 'str'>
После разбора: <class 'dict'>
Команда: {'type': 'tool', 'tool': 'find_notes', 'query': 'возврат'}
Инструмент: find_notes
Запрос: возврат
```

`str` - строка, `dict` - словарь. Строки "Инструмент" и "Запрос" демонстрация получает из полей словаря, который вернула ваша функция. Дальше демонстрация пробует фразу "Сейчас поищу" и список `'[]'`, и для каждого срабатывает своя проверка. Для готовых проверок запустите `tests/test_lesson.py`.

## Попробуйте сломать

Замените в своей функции `return command` на `return text` и снова запустите `demo_check.py`. Разбор по-прежнему выполняется, но функция возвращает исходную строку, и чтение поля `'tool'` в демонстрации закончится ошибкой. Важно не просто вызвать `json.loads`, а передать результат дальше. Верните `return command`.

У проверки есть граница. Словарь `{'type': 'tool', 'tool': 'delete_file'}` пройдёт обе проверки `parse_decision`: это правильный JSON и это словарь. Отклонит такое действие `dispatch_tool`, где записан список разрешённых инструментов. Разбор формата и разрешение действий - разные обязанности, и смешивать их не стоит.
