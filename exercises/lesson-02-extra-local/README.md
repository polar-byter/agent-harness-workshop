# Модель внутри программы Python

Отдельное необязательное упражнение после раздела 2. Основной проект не меняем.
Проверяемый маршрут: Windows x64, Python 3.14, llama-cpp-python 0.3.36, CPU.

1. Откройте эту папку в новом окне PyCharm через File -> Open.
2. Допишите send_local в local_model.py по TASK.md.
3. Запустите demo_check.py через правую кнопку -> Run 'demo_check'. Здесь модель не нужна.
4. Для настоящего запуска установите зависимости из requirements.txt в окружение этой папки:

```powershell
python -m pip install --only-binary=:all: -r requirements.txt
```

5. Запустите check_install.py и убедитесь, что библиотека загрузилась.
6. Скачайте файл по инструкции models/README.md.
7. Запустите demo.py. Ответ появится в нижней панели Run.

При новом Run модель загружается заново. Внутри одного запуска объект можно использовать
для нескольких обращений. Готовые настройки Ollama и API этот пример не читает.
