# От поиска в регламенте до кодирующего агента

Через весь курс проходит один пример: помощник отвечает клиентам интернет-магазина по регламенту возвратов. Шаг за шагом мы передаём программе всё больше работы. Сначала она находит пункты регламента, затем модель отвечает по найденному, потом сама просит программу выполнить поиск, а программа следит за лимитами и ведёт журнал. В последнем разделе агент предлагает правку кода, а программа применяет её только с согласия человека и проверяет тестами.

Каждый урок закрывает один вопрос из истории MWS, с которой начинается [введение](00-introduction.md): есть ли нужный пункт в источнике, нашёл ли его поиск, что получила модель, кто разрешил действие.

У каждого урока свой архив. В нём всё, что написано в прошлых уроках, уже работает, а текущая функция начата и остановлена на `NotImplementedError`. Можно продолжать в своём проекте или открыть архив урока в новом окне PyCharm: первый путь сохраняет ваш код, второй позволяет пройти урок независимо.

Если какое-то слово забылось, загляните в [памятку терминов](terms.md). Если трудно ориентироваться в окнах редактора, есть [схема поиска файла и запуска](pycharm.md). Начните с [подготовки](01-note-search/00-setup.md).
