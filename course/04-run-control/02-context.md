# Урок 2. Выбираем историю для следующего шага (Context Engineering)

[Открыть исходники этого урока](../../exercises/lesson-04-02-context/README.md) / [Подсказки рядом с кодом](../../exercises/lesson-04-02-context/TASK.md)

> **Где мы находимся:** По мере работы агента история его шагов растет. 
> 
> Если передавать модели всю историю целиком, контекстное окно переполнится, запросы станут медленными и дорогими.
> 
> В этом уроке мы реализуем стратегию скользящего окна контекста: постоянная задача + последние N шагов:
> 
> `Вся история (10 шагов) -> [фильтрация окна] -> последние 2 шага -> модель`

---

## Архитектура контекстного окна

Принцип **Context Engineering**:
* Сама исходная задача клиента передается всегда (она не должна потеряться).
* Из промежуточных действий агента мы оставляем только последние 2-3 шага. Старые промежуточные результаты срезаются (`history[-k:]`).

Это сохраняет фокус внимания нейросети и экономит токены.
