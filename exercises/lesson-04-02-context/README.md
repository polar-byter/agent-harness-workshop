# Выбираем историю для следующего шага

Откройте в PyCharm папку `lesson-04-02-context` из этого архива.

Слева: View -> Tool Windows -> Project. Разверните корневую папку. Откройте `demo.py` двойным щелчком, затем нажмите правой кнопкой в редакторе и выберите Run. Вывод появится внизу, в Run.

Текущие задания:

- `control.py` -> `select_context`

Предыдущие части даны в готовом виде для независимого старта. В текущих функциях уже подготовлено начало; незавершённый участок отмечен raise NotImplementedError(...). Допишите его по уроку или TASK.md и удалите эту строку. Функции следующих заданий пока остаются заглушками. До завершения demo.py сообщает имя незаполненной функции.

После реализации ожидается:

{'task': 'Найди Python', 'events': [{'step': 2}, {'step': 3}]}

Необязательная проверка: tests/test_lesson.py -> class LessonTests -> Run. Проверки этого архива относятся только к текущему заданию.

Python 3.12 или новее; внешние библиотеки не нужны. По умолчанию сеть не используется. Если есть demo_live.py, он выполняет настоящий запрос только при отдельном запуске с настройками API.


## Запуск с подключённой моделью

Сначала завершите текущую функцию по подсказкам выше. Основной `demo.py` использует модель, настроенную в уроке 2.4. Подключение общее для всех каркасов на этом компьютере. Для проверки текущей функции без обращения к модели запустите `demo_check.py`. Его точный учебный вывод не является результатом настоящей модели. Для смены подключения запустите `configure_model.py`.
