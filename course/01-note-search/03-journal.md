## Посмотрим на данные

`result` - словарь с полями результата, а `path` - путь к журналу. В отличие от списка словарь связывает имя поля со значением: `result["query"]` вернёт запрос. JSON позволяет записать такую структуру текстом и затем прочитать обратно. Здесь выбираем JSONL: несколько независимых JSON-записей, по одной на строку.

```python
result = {'query': 'python', 'matches': ['Python lists']}
text = json.dumps(result, ensure_ascii=False)
# '{"query": "python", "matches": ["Python lists"]}' 
```

Этот фрагмент поясняет данные и конструкции; в учебный модуль его целиком копировать не требуется. Рабочие значения уже подготовлены в `demo.py`.

## Соберём функцию с подсказками

У нас уже есть словарь результата. Чтобы сохранить его, сначала превращаем словарь в текст JSON, а затем дописываем этот текст в файл. В каркасе первая часть уже выполнена: переменная `text` содержит готовую строку. Осталось записать её, не стирая прежние результаты.

В файле текущего задания уже есть начало функции. Допишите её по заготовке ниже: `...` обозначает место для вашего выражения, а не готовую команду. Когда заполните пропуски, удалите строку `raise NotImplementedError(...)` из каркаса. Заголовок `def` в файле уже есть - вторую функцию с тем же именем создавать не нужно.

```python
def write_result(path: Path, result: dict) -> None:
    text = json.dumps(result, ensure_ascii=False)
    with path.open('a', encoding='utf-8') as stream:
        stream.write(...)
```

В пропуске нужно передать `text + "\n"`: сам JSON и один перевод строки после него. Без `"\n"` следующий результат приклеится к предыдущему, и отдельные записи будет трудно прочитать.

`path.open("a", ...)` открывает файл для добавления в конец. Буква `w` здесь изменила бы смысл: старый журнал был бы очищен. `with` закрывает файл после записи; `stream` - имя, под которым мы работаем с открытым файлом внутри блока. В этой функции `return` с результатом не нужен: её работа - сохранить запись.

## Найдём файл запуска и проверим результат

В левой панели **Project -> lesson-01-03-journal -> demo.py** откройте файл двойным щелчком. Нажмите правой кнопкой внутри открытого редактора и выберите **Run 'demo'**. Внизу появится окно **Run** с выводом именно этого файла. Отдельная общая кнопка "запустить проект" нам здесь не нужна: выбираем конкретный демонстрационный файл. Если панель с файлами скрыта, вернитесь к **View -> Tool Windows -> Project**. Если Run скрыто - **View -> Tool Windows -> Run**.

До завершения функции появится сообщение "Допишите ... по подсказкам урока". После реализации ожидаем:

```text
{"query": "python", "matches": ["Python lists"]}
```

Для дополнительного контроля откройте в этом же проекте `tests/test_lesson.py`, найдите `class LessonTests`, нажмите правой кнопкой по имени класса и выберите Run. Это необязательная проверка текущего задания; внутреннее устройство тестов сейчас разбирать не нужно.

Сейчас ваша работа - `write_result` в `journal.py`; затем повторный запуск `demo.py`.
