# От поиска заметок до собственного учебного агента

По ходу практики будем знакомиться с терминами, которые встречаются в статьях и обсуждениях ИИ. Если нужно вспомнить слово, откройте [памятку с примерами из нашего кода](terms.md). Учить её до первого урока не требуется.

Если хотите сначала понять, как курс связан с вашей работой аналитика, руководителя или специалиста в своей области, начните с раздела [для кого эти уроки и что они дадут](who-this-is-for.md). Основной интерес здесь - понимать и проверять работу агентной системы; Python осваиваем как инструмент практики.

Мы будем постепенно передавать программе всё больше работы. Сначала она сможет найти данные. Затем модель получит эти данные для ответа, научится запрашивать инструменты, а наш harness - ограничивать действия и сохранять историю. В конце предложим агенту небольшое изменение кода и проверим его результат.

Каждый урок ниже имеет собственный архив. В уроках реализации предыдущие части подготовлены для старта, а текущая функция начата и остановлена на `NotImplementedError`. В уроке подключения функции уже готовы: задача состоит в настройке и проверке настоящей модели. Можно продолжать свой проект или открыть соответствующий каркас в новом окне PyCharm. Первый путь сохраняет вашу реализацию, второй позволяет отдельно пройти конкретный урок.

Начните с [открытия первого проекта](01-note-search/00-setup.md). Если нужно разобраться с окнами редактора, есть [схема поиска файла и запуска](pycharm.md).

Второй подпроект завершается обязательным подключением модели: через API или локально. Все последующие основные `demo.py` используют это подключение. Фиксированные ответы остаются в `demo_check.py` и тестах, чтобы отдельно проверять код. В третьем используем простой учебный протокол команд в JSON; это не нативный function calling API. В четвёртом считаем шаги и вызовы, а не стоимость токенов. Пятый подпроект выполняет один проход изменения с явным согласием и тестами; полноценная изоляция исполнения и самостоятельные повторы остаются дальнейшим развитием.
