# Урок 3. Сохраняем историю выполнения (Tracing)

[Открыть исходники этого урока](../../exercises/lesson-04-03-trace/README.md) / [Подсказки рядом с кодом](../../exercises/lesson-04-03-trace/TASK.md)

> **Где мы находимся:** Когда агент выполняет многошаговую задачу, нам нужен полный подробный след каждого его решения.
> 
> В этом уроке мы записываем полную трассировку (Trace) работы агента в структурированный JSONL-файл:
> 
> `Шаг агента -> запись в trace.jsonl -> аудит каждого решения и вызова инструмента`

---

## Что входит в трейс?
Каждое событие трейса содержит:
1. Номер шага (`step`).
2. Решение модели (`decision`).
3. Результат выполнения инструмента (`tool_result`).
4. Время выполнения.

По такому файлу инженер может посекундно воспроизвести ход мыслей агента при разборе любого инцидента.
