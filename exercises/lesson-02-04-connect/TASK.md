# Подключаем модель

В этом уроке функции уже готовы. Запустите `configure_model.py` через Run в PyCharm.
Выберите один маршрут из статьи: OpenRouter, VseGPT или Ollama. Сохраните настройки.
Для Ollama сначала установите приложение и скачайте `qwen3:0.6b`.
Затем откройте `demo.py` и выполните Run. Внизу, в Run, появятся вопрос, заметки и ответ модели.
Проверьте ответ на исходном вопросе. Затем поменяйте только вопрос на «Что заметки говорят о работе с файлами?».
Заметку оставьте прежней: ожидаем сообщение о нехватке сведений. Верните исходный вопрос после опыта.
Готовый ответ из файла проверяется отдельно через `demo_check.py` и не подтверждает подключение.
Ключ хранится вне проекта в пользовательских настройках. Не публикуйте файл connection.json.
Все последующие каркасы читают эти же настройки.
