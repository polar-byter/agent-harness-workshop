# Урок 1. Выполняем команду поиска (Диспетчер инструментов)

[Открыть исходники этого урока](../../exercises/lesson-03-01-tools/README.md) / [Подсказки рядом с кодом](../../exercises/lesson-03-01-tools/TASK.md)

> **Где мы находимся:** Начинаем третий подпроект курса - создание настоящего ИИ-агента!
> 
> Раньше мы сами вызывали поиск и отдавали результат модели. Теперь всё меняется: **модель сама решает, какое действие ей нужно**, и присылает нашей программе команду в формате JSON.
> 
> В этом уроке мы создадим диспетчер инструментов `dispatch_tool`: защитный барьер (гардрейл), который проверяет команду модели, выполняет разрешенное действие и возвращает результат:
> 
> `Команда модели в JSON -> [dispatch_tool: проверка прав] -> вызов функции -> возврат результата`

---

## Главный закон безопасности ИИ-агентов

Запомните золотое правило: **нейросеть никогда не выполняет код сама!**

Модель - это всего лишь текстовый генератор. Когда агент "вызывает инструмент" (Function Calling), он просто генерирует JSON-строку:
```json
{
  "tool": "search",
  "query": "возврат"
}
```

А вот выполнять это действие или нет - решает **ваша программа-обвязка (harness)**:
* Если модель запросила разрешенный инструмент `"search"` - программа вызывает нашу безопасную функцию `run_search`.
* Если модель галлюцинирует и просит выполнить неизвестный инструмент (например, `"delete_database"` или `"send_email"`) - программа категорически отказывает и бросает исключение!

Такие защитные фильтры в коде называют **гардрейлами (Guardrails)**.

## Напишите код сами

Откройте `agent.py` и найдите функцию `dispatch_tool`:

```python
def dispatch_tool(command: dict, notes_path: Path, journal_path: Path) -> dict:
    raise NotImplementedError("Допишите dispatch_tool по подсказкам урока")
```

Замените строчку `raise NotImplementedError(...)` следующим кодом и заполните два пропуска `...`:

```python
    tool_name = command.get('tool')
    if tool_name == 'search':
        query = command.get('query', '')
        return run_search(notes_path, ..., journal_path)
    raise ValueError(f'Неизвестный инструмент: {tool_name}')
```

1. Во второй аргумент функции `run_search` передайте поисковую фразу: `query`.
2. Если имя инструмента не равно `'search'`, срабатывает строгий аварийный сигнал: `raise ValueError(...)`.

## Запустим и проверим

1. Запустите `demo.py` (**Run 'demo'**).
2. Программа сымитирует команду от модели:
   `command = {'tool': 'search', 'query': 'возврат'}`
3. Функция `dispatch_tool` проверит разрешение, выполнит поиск через наш модуль `app.py` и вернет структурированный словарь:

```text
{'query': 'возврат', 'status': 'found', 'matches': ['Возврат товара возможен в течение 14 дней.', ...]}
```
