# Подготовка. Откроем проект и сделаем первый запуск

> **Где мы находимся:** Начинаем практическую работу. Вводная часть осталась позади, теперь мы открываем среду разработки PyCharm, проверяем готовность Python и запускаем наш первый проверочный скрипт.

Через весь курс сквозной нитью проходит один понятный жизненный пример — правила возврата товаров в интернет-магазине:

```text
Возврат товара возможен в течение 14 дней.
Доставка по городу занимает 1 день.
ВОЗВРАТ денег производится на карту покупателя.
```

Когда покупатель спрашивает о возврате денег или товара, умный помощник должен быстро отыскать первый и третий пункты, а пункт про доставку отсеять как нерелевантный. Поисковую функцию мы напишем в Уроке 1, чуть позже научим программу считывать регламент из файла на диске и вести журнал найденного.

Сегодня задача простая и спокойная: открыть проект и убедиться, что Python на вашем компьютере запускается без ошибок.

---

## Как устроен проект

Учебный каркас состоит из нескольких файлов. В `notes.py` будет жить чтение и поиск пунктов, `app.py` свяжет их в единый сценарий, а `journal.py` сохранит результат в отчёт.

Вам не придётся писать всё с нуля: в каждом уроке мы делаем ровно один небольшой шаг. Рядом лежит папка `tests` с готовыми автоматическими проверками (юнит-тестами): они вызывают ваш код на тестовых данных и проверяют, правильный ли ответ получился.

## 1. Установим PyCharm и Python (если ещё не установлены)

1. **PyCharm Community Edition** — удобная и бесплатная среда для работы с кодом на Python. Скачайте её с [официального сайта JetBrains](https://www.jetbrains.com/pycharm/download/) и установите.
2. **Python** — сам интерпретатор языка, который исполняет команды. Если он ещё не стоит, скачайте установщик для Windows с [python.org](https://www.python.org/downloads/windows/) (версия 3.12 или новее).
   * **Важно:** на самом первом экране установщика обязательно поставьте галочку **«Add python.exe to PATH»**, а затем нажмите **Install Now**.

---

## 2. Распакуем и откроем каркас урока

1. Скачайте [каркас первого урока](../../downloads/lesson-01-01-search.zip?raw=true).
2. Нажмите на скачанный архив правой кнопкой мыши и выберите **Извлечь всё...**. Появится папка `lesson-01-01-search`.
3. В PyCharm нажмите **Open** (или в верхнем меню **File -> Open**) и выберите именно распакованную папку `lesson-01-01-search`.
4. Слева откройте панель проекта (**View -> Tool Windows -> Project**). Разверните папку `lesson-01-01-search`.
5. Найдите файл `start.py` и откройте его двойным щелчком. Это крошечный файл для проверки того, что окружение собрано правильно.

---

## 3. Выберем интерпретатор Python для проекта

PyCharm должен знать, какой именно установленный Python запускать:

1. Откройте **File -> Settings** (на macOS: **PyCharm -> Settings**).
2. Перейдите в раздел **Project: lesson-01-01-search -> Python Interpreter**.
3. Если там уже выбран Python версии 3.12 или новее — всё отлично, просто закройте окно настроек.
4. Если поле пустое (написано **No interpreter**):
   * Нажмите **Add Interpreter -> Add Local Interpreter...**
   * Выберите слева **Virtualenv**, а в поле **Base interpreter** укажите установленный Python (обычно он находится в `C:\Users\<имя>\AppData\Local\Programs\Python\Python312\python.exe`).
   * Нажмите **OK**.

---

## 4. Сделаем первый тестовый запуск

В окне редактора с открытым файлом `start.py`:
1. Щёлкните правой кнопкой мыши прямо по тексту кода.
2. В появившемся меню выберите **Run 'start'**.

Внизу экрана откроется панель **Run**, и в ней появится заветная строка:

```text
Проект открыт. Python работает.
```

Поздравляем! Среда полностью настроена, интерпретатор готов к работе. Теперь можно уверенно переходить к первому уроку.
