> **Где мы находимся:** Начинаем четвертый подпроект - управление выполнением, бюджетом и качеством агента.
> 
> Автономный агент не должен иметь неограниченный доступ к ресурсам. В этом уроке мы внедряем строгий счетчик шагов и баланс действий, защищающий систему от перерасхода средств:
> 
> `Запуск задачи -> [Счетчик шагов: осталось N] -> если 0 -> вежливая остановка с отчетом`

---

## Почему одного `max_steps` недостаточно?

В прошлом уроке при исчерпании шагов программа просто выбрасывала `TimeoutError`. Но в реальном клиентском сервисе бросать фатальную ошибку нельзя - клиент увидит сломанный экран "500 Internal Server Error".

В надежном harness агент при исчерпании бюджета должен:
1. Корректно зафиксировать факт перерасхода в аудит-логе.
2. Вернуть пользователю вежливый частичный ответ: *"Я выполнил часть поиска, но задача потребовала слишком много шагов. Пожалуйста, обратитесь к оператору"*.

## Напишите код сами

Откройте `agent.py` и добавьте контроль расхода бюджета действий в функции `run_agent`:

```python
    steps_left = budget
    for step in range(budget):
        steps_left -= 1
        decision = decide(task, history)
        if decision.get('action') == 'finish':
            return decision.get('answer', '')
        # Обработка инструмента...
    return 'Не удалось завершить задачу в рамках выделенного бюджета шагов.'
```
