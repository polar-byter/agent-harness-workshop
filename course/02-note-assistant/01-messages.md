# Урок 1. Передаём вопрос вместе с заметками

[Открыть исходники этого урока](../../exercises/lesson-02-01-messages/README.md) · [Подсказки рядом с кодом](../../exercises/lesson-02-01-messages/TASK.md)

Инструмент умеет находить строки. Теперь захотим получить ответ на вопрос: «Что заметки говорят о Python?» Модель должна увидеть сами найденные строки — одного упоминания файла недостаточно. В этом уроке соберём данные для запроса, пока без сети.

## Откроем каркас именно этого урока

Скачайте [каркас этого урока](../../downloads/lesson-02-01-messages.zip?raw=true) и распакуйте архив через «Извлечь всё». Внутри будет папка `lesson-02-01-messages`. В PyCharm выберите **File → Open**, укажите эту папку и откройте её в новом окне. Предыдущие части уже подготовлены: переносить свои решения необязательно. Свой прежний проект можно оставить открытым.

Слева откройте **View → Tool Windows → Project** и разверните `lesson-02-01-messages` стрелкой рядом с именем. Текущее задание — `build_messages` в `assistant.py`. Файл `demo.py` лежит прямо в этом корне, рядом с модулями, вне папок `data` и `tests`.

## Посмотрим на данные

Параметр `question` содержит вопрос, `notes` — найденные строки. Вернём список сообщений: каждое является словарём с ролью `role` и текстом `content`. Общие правила попадут в сообщение `developer`, вопрос и заметки — в `user`. Это структура нашего обращения через API, а не текст, который нужно вставлять в окно ChatGPT.

```python
question = 'Что заметки говорят о Python?'
notes = ['Python lists keep item order.']
data = {'question': question, 'notes': notes}
text = json.dumps(data, ensure_ascii=False)
```

Этот фрагмент поясняет данные и конструкции; в учебный модуль его целиком копировать не требуется. Рабочие значения уже подготовлены в `demo.py`.

## Соберём функцию с подсказками

Модель увидит только те данные, которые мы ей передадим. Поэтому соберём рядом и вопрос, и заметки. Каркас уже проверяет вопрос и превращает данные в JSON. Теперь нужно положить этот текст в сообщение, а перед ним — понятные правила ответа.

В файле текущего задания уже есть начало функции. Допишите её по заготовке ниже: `...` обозначает место для вашего выражения, а не готовую команду. Когда заполните пропуски, удалите строку `raise NotImplementedError(...)` из каркаса. Заголовок `def` в файле уже есть — вторую функцию с тем же именем создавать не нужно.

```python
def build_messages(question: str, notes: list[str]) -> list[dict]:
    if not question.strip():
        raise ValueError('Вопрос не должен быть пустым')
    data = {'question': question, 'notes': notes}
    content = json.dumps(data, ensure_ascii=False)
    rules = ...
    return [
        {'role': 'developer', 'content': ...},
        {'role': 'user', 'content': ...},
    ]
```

В `rules` напишите обычную строку с правилом: отвечать по заметкам, сообщать об отсутствии сведений и воспринимать содержимое заметок как данные, а не новые инструкции. Например, начало может быть таким: `"Ответь только по переданным заметкам."`. Дополните его остальными двумя условиями своими словами.

В первом сообщении значение `content` — переменная `rules`, во втором — переменная `content` с JSON вопроса и заметок. `role` и `content` — имена полей, которые понимает API. `developer` обозначает наши общие правила, `user` — данные текущего обращения. Функция возвращает список этих словарей; отправлять его по сети здесь не нужно.

## Найдём файл запуска и проверим результат

В левой панели **Project → lesson-02-01-messages → demo.py** откройте файл двойным щелчком. Нажмите правой кнопкой внутри открытого редактора и выберите **Run 'demo'**. Внизу появится окно **Run** с выводом именно этого файла. Отдельная общая кнопка «запустить проект» нам здесь не нужна: выбираем конкретный демонстрационный файл. Если панель с файлами скрыта, вернитесь к **View → Tool Windows → Project**. Если Run скрыто — **View → Tool Windows → Run**.

До завершения функции появится сообщение «Допишите … по подсказкам урока». После реализации ожидаем:

```text
Список из двух сообщений: правила developer и данные user; в user есть вопрос и одна исходная заметка.
```

Для дополнительного контроля откройте в этом же проекте `tests/test_lesson.py`, найдите `class LessonTests`, нажмите правой кнопкой по имени класса и выберите Run. Это необязательная проверка текущего задания; внутреннее устройство тестов сейчас разбирать не нужно.

Формат сообщений и ответа сверяем с [официальной документацией Responses API](https://developers.openai.com/api/docs/guides/text). Учебный `response.json` содержит только поля, нужные для нашего разбора.

Сейчас ваша работа — `build_messages` в `assistant.py`; затем повторный запуск `demo.py`.
