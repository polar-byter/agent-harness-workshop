# Подсказки к текущему заданию

> **Где мы.** Мы умеем собрать запрос к модели. Прежде чем отправлять его, разберёмся с обратной стороной: в каком виде приходит ответ и как достать из него текст для клиента.
> `сообщения -> модель -> [ответ сервиса -> текст]`

Сервис модели возвращает не одну фразу, а словарь со служебными полями: состояние ответа, список его частей, тип каждой части. Если напечатать его целиком, клиент увидит служебную структуру. Если взять первое попавшееся поле, можно пропустить часть текста или принять оборванный ответ за готовый. Поэтому напишем функцию `extract_answer`, которая проверит, что ответ завершён, соберёт текстовые части и вернёт обычную строку.

Работать будем с подготовленным файлом `data/response.json`, повторяющим формат настоящего ответа. Так мы заранее знаем, что в нём лежит, и можем проверить свою функцию до подключения модели.

Откройте `assistant.py` -> функция `extract_answer`.

## Напишите сами

В начале `extract_answer` уже проверен статус и создан пустой список `parts`. Замените `raise NotImplementedError(...)` кодом ниже и заполните пропуски:

```python
    for item in response.get('output', []):
        if item.get('type') == 'message':
            for part in item.get('content', []):
                if part.get('type') == 'output_text':
                    parts.append(...)
    answer = '\n'.join(parts).strip()
    if not answer:
        raise ValueError('В ответе нет текста')
    return ...
```

1. В `append` передайте текст части: `part['text']`.
2. В `return` - готовую строку `answer`.

Здесь два цикла, один внутри другого. Внешний перебирает элементы `output` и выбирает сообщения, внутренний перебирает части сообщения и выбирает текстовые. Метод `'\n'.join(parts)` соединяет найденные куски через перевод строки, а `strip()` убирает пробелы по краям. Если текста не нашлось совсем, функция сообщит об ошибке, а не вернёт пустую строку, которую можно принять за ответ.

## Запустим

Откройте `demo.py` и выберите **Run 'demo'**. В окне Run должно появиться:

```text
Вернуть товар можно в течение 14 дней.
```

Демонстрация прочитала словарь из `response.json`, передала его в вашу функцию и напечатала то, что та вернула. Нового ответа модели здесь нет: мы достали уже записанный текст.
