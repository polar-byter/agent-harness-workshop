# Агентная мастерская

Вы уже можете прикрепить документ к готовому ИИ-помощнику и попросить найти нужное. В этом курсе я предлагаю заглянуть за эту привычную возможность: написать инструмент поиска, подключить модель и собрать программу, которая выполняет её запросы, сохраняет историю и проверяет результат.

Начнём с нескольких заметок и постепенно дойдём до небольшого агента, предлагающего изменение Python-кода. Python будем осваивать по дороге: в каждом уроке есть понятная задача, подготовленное начало функции и подсказки к недописанным местам.

**[Начать с введения](course/00-introduction.md)** · **[Все уроки](course/README.md)** · **[Как найти файл и запустить его в PyCharm](course/pycharm.md)**

## Как здесь учиться

Откройте [подготовку первого проекта](course/01-note-search/00-setup.md). Текст можно читать прямо на GitHub: схемы, анимации, примеры и переходы между уроками находятся рядом. Для практики скачайте архив нужного урока по ссылке в статье и откройте распакованную папку в PyCharm.

Если удобнее получить всё сразу, на этой странице выберите **Code → Download ZIP**, распакуйте репозиторий и откройте в PyCharm нужную папку внутри `exercises`. Например, для первого поиска — `exercises/lesson-01-01-search`, а не весь репозиторий. Установленный Python выполняет код; сам просмотр файла на GitHub его не запускает.

У каждого урока есть отдельный каркас: предыдущие части уже подготовлены, текущую функцию предстоит дописать. В статье и в `TASK.md` рядом с кодом объяснено, что сделать. Поэтому можно пройти курс последовательно или отдельно вернуться к нужной теме.

## Что понадобится

Для начала достаточно Python 3.12 или новее и PyCharm. Каркасы используют стандартную библиотеку. Сначала примеры работают локально с подготовленными данными; отдельные сетевые запуски появляются позже и требуют собственного доступа к API. Они не включаются автоматически.

Проверки сборки репозитория проверяют материалы и запуск каркасов. Тесты написанного вами решения запускаются отдельно после упражнения — этот шаг объясняется в уроках.
