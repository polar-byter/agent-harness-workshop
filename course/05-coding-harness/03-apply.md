# Урок 3. Применяем согласованное предложение (Human-in-the-Loop)

[Открыть исходники этого урока](../../exercises/lesson-05-03-apply/README.md) / [Подсказки рядом с кодом](../../exercises/lesson-05-03-apply/TASK.md)

> **Где мы находимся:** Ключевой принцип безопасности современных помощников разработчика (Cursor, Claude Code):
> 
> Программа показывает человеку diff и спрашивает явное согласие: *"Применить это изменение? [y/n]"*. Без подтверждения ни один байт на диске не изменится:
> 
> `Показ diff -> запрос согласия пользователя -> [y] -> запись патча на диск`

---

## Архитектура Human-in-the-Loop (HITL)

Если пользователь нажал `y` (yes):
* Программа аккуратно записывает новое содержимое в файл на диске.

Если пользователь нажал `n` (no):
* Программа останавливается, файл остается нетронутым, а в журнал записывается событие отказа.

Человек всегда держит руку на кнопке контроля.
