# Подготовка. Откроем проект и сделаем первый запуск

> **Где мы.** Курс начинается с вопроса из истории MWS: нашла ли программа нужный пункт инструкции. Первым делом напишем поиск по регламенту, а для этого подготовим PyCharm и Python.

Через весь курс проходит один пример - регламент возвратов интернет-магазина. В нём несколько пунктов:

```text
Возврат товара возможен в течение 14 дней.
Доставка по городу занимает 1 день.
ВОЗВРАТ денег производится на карту покупателя.
```

Когда клиент спрашивает о возврате, помощник должен найти первый и третий пункты, а второй, про доставку, пропустить. Поиск напишем в первом уроке, позже научим программу читать регламент из файла и записывать, что она нашла. Сегодня задача скромнее: открыть проект и убедиться, что Python работает.

Проект состоит из нескольких файлов. В `notes.py` будут чтение и поиск пунктов, `app.py` соединит их в одну операцию, а `journal.py` сохранит результат. Писать всё сразу не придётся: в первом уроке займёмся только поиском. Рядом лежит папка `tests` с готовыми проверками: они вызывают вашу функцию на заранее выбранных данных и сравнивают ответ с ожидаемым. Программисты называют такие проверки юнит-тестами. Как ими пользоваться, расскажу после первого работающего поиска.

## Установим PyCharm и Python

PyCharm - программа, в которой удобно писать и запускать код на Python. Скачайте её с [сайта JetBrains](https://www.jetbrains.com/pycharm/download/) и установите: для курса хватает бесплатной версии.

Кроме редактора понадобится сам Python, который выполняет код. Если его ещё нет, возьмите установщик для Windows на [официальном сайте](https://www.python.org/downloads/windows/). Подойдёт версия 3.12 или новее. В первом окне установщика поставьте галочку **Add python.exe to PATH**, затем нажмите **Install Now**. Если Python уже установлен, ставить его заново не нужно.

## Откроем каркас первого урока

Скачайте [каркас первого урока](../../downloads/lesson-01-01-search.zip?raw=true), нажмите на архив в Проводнике правой кнопкой и выберите **Извлечь всё**. Внутри появится папка `lesson-01-01-search`. На стартовом экране PyCharm нажмите **Open** и выберите именно её. Если редактор уже открыт, используйте **File -> Open**.

Слева откройте **View -> Tool Windows -> Project**: появится дерево файлов. Разверните стрелкой папку `lesson-01-01-search`. Прямо в ней, рядом с `notes.py`, лежит `start.py`. Откройте его двойным щелчком: этот файл только печатает короткое сообщение и помогает проверить, что Python запускается.

## Выберем Python для проекта

PyCharm должен знать, каким установленным Python выполнять код. Откройте **File -> Settings -> Python -> Interpreter** (в некоторых версиях **Project: lesson-01-01-search -> Python Interpreter**). Если в поле уже указан Python 3.12 или новее, всё готово, закройте окно.

Если поле пустое или там написано **No interpreter**, нажмите **Add Interpreter -> Add Local Interpreter**. В открывшемся окне слева выберите **Virtualenv**, а в поле **Base interpreter** - установленный Python. Если списка нет, нажмите на значок папки и найдите `python.exe`; обычно он лежит в `C:\Users\<имя>\AppData\Local\Programs\Python\Python312`. Место для окружения оставьте предложенное и нажмите **OK**. Виртуальное окружение - отдельная папка для библиотек этого проекта; сейчас ничего устанавливать в неё не будем. Подробности есть в [инструкции JetBrains](https://www.jetbrains.com/help/pycharm/configuring-python-interpreter.html).

## Сделаем первый запуск

В редакторе с открытым `start.py` нажмите правой кнопкой и выберите **Run 'start'**. Внизу откроется окно **Run**, и в нём появится строка:

```text
Проект открыт. Python работает.
```

Значит, PyCharm нашёл Python и выполнил файл проекта. Можно переходить к [первому уроку](01-search.md).

Если PyCharm пишет, что интерпретатор не выбран, вернитесь к предыдущему разделу. Если в меню нет пункта **Run**, проверьте, что открыт `start.py` из распакованной папки, а не файл внутри ZIP-архива. Схема окон PyCharm есть в разделе [как найти файл и запустить пример](../pycharm.md).
